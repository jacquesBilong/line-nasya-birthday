# Site anniversaire 

## Accès de test
- Invité : `TOM`, `BILONG`, `CECILIA`, `LINE`
- Organisateur : `Lineorganisation`
- Admin : `LineAdminVIP2026`

## Rôles
- Invité : accueil + confirmation de présence.
- Organisateur : suivi des présences et besoins prestataires/traiteur.
- Admin : gestion des invités, mots de passe, messages WhatsApp et exports.

## Notes
Les données sont stockées localement dans le navigateur pour cette version statique. Pour recevoir les confirmations en temps réel depuis tous les invités, il faudra connecter un backend ou Google Sheets/Formspree.
